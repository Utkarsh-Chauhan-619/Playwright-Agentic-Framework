# Specs

This directory contains test plans created by the Playwright Test Planner agent.

Test plans are written in Markdown format and serve as the input for the Playwright Test Generator agent to create Python pytest tests.

## Plan Format

Each test plan should include:
- Overview of the feature/application being tested
- Multiple test suites grouped by functionality
- Individual test scenarios with step-by-step instructions
- Expected outcomes for each step
- Seed file reference (typically `tests/seed.spec.py`)
